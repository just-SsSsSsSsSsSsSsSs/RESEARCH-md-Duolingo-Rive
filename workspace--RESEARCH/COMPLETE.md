## 🚀 كيفية التشغيل

### 1. تشغيل محلي:
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve .

# أو باستخدام PHP
php -S localhost:8000
```

### 2. نشر على GitHub Pages:
1. ارفع الملفات على GitHub
2. اذهب إلى Settings > Pages
3. اختر branch main
4. احفظ

### 3. نشر على Netlify/Vercel:
1. اربط المستودع
2. اختر branch main
3. انشر تلقائياً
