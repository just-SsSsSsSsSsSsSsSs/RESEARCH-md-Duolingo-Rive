# html-mobile-audio — ألعاب وحلقات سليم التفاعلية 🎮🌙

محتوى تعليمي تفاعلي عربي (ملفات HTML شغالة أوفلاين + حلقات صوتية MP3 + سكريبتات Word) لطفل في الصف الثالث الابتدائي — الصوت مدمج داخل الصفحات (voice-01)، فكل ملف يشتغل من غير إنترنت.

## 📁 المحتوى
### quran-albayyinah/ — سورة البيّنة
- `سورة_البينة_مصحف_تفاعلي.html` — مصحف تفاعلي: رسم عثماني + ألوان تجويد + تظليل الآية مع التلاوة (~٢٠ دقيقة تلقين)
- `تلقين_سورة_البينة.mp3` — مسار التلقين الصوتي منفصلًا
- `build.py` / `template.html` / `audio/` — كود ومواد البناء

### selim-math-arabic/ — ألعاب الرياضيات والعربي
- `تطبيق_سر_التقسيم_السحري_سليم_بالصوت.html` — لعبة خاصية تجزئة المضروب (بالصوت)
- `تطبيق_ازرع_نبتة_سليم.html` — تقويم نص الاستماع «ازرع نبتة» (فصحى)
- `تطبيق_ازرع_نبتة_سليم_بالبلدي.html` — نفس التقويم + شرح بالبلدي لكل سؤال
- `سليم_رحلة_سر_التقسيم_السحري_خواص_الضرب.mp3` + سكريبت Word — الحلقة الصوتية للدرس
- `build_*.py` / `test_*.js` / `snd*/` — كود البناء والاختبارات والمقاطع الخام

### episodes-selim/ — حلقات جداول الضرب وقصص القيم
- حلقات سليم وكرمة وكندا (MP3 + Word): جدول ٣، جدول ٤، قصة الدين
